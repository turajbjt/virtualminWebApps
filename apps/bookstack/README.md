# BookStack for Virtualmin

[BookStack](https://www.bookstackapp.com/) is a simple, self-hosted, and opinionated wiki platform built on Laravel.

## Features in this Virtualmin Module
* **Pre-configured Laravel Environment**: Automatically writes database parameters into `.env` and generates the application encryption key (`artisan key:generate`).
* **Automated Migrations**: Automatically runs database migrations on install and upgrade.
* **Organized Layout**: Supports books, chapters, and pages hierarchy.
