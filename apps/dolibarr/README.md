# Dolibarr ERP & CRM for Virtualmin

[Dolibarr](https://www.dolibarr.org/) is an all-in-one ERP and CRM suite for small and medium-sized enterprises, foundations, and freelancers.

## Features in this Virtualmin Module
* **Virtualmin Pro Replacement**: Free, unrestricted community installer.
* **Pre-configured Environment**: Automatically generates `conf/conf.php` with database credentials and secure document paths.
* **External Documents Directory**: Safely stores uploaded business documents in `/home/<domain>/dolibarr-documents` outside `public_html`.
