# Flarum for Virtualmin

[Flarum](https://flarum.org/) is the next-generation, open-source forum software designed to be simple, fast, and responsive.

## Features in this Virtualmin Module
* **Composer-driven Deployment**: Automatically pulls dependencies using Composer.
* **Pre-configured Database**: Prepares MariaDB/MySQL database and user credentials.
* **Subdirectory Flexibility**: Supports installation to document root or custom subfolder (`/forum/`).
