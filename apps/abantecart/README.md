# AbanteCart for Virtualmin

[AbanteCart](https://www.abantecart.com/) is a free, powerful PHP-based e-commerce solution.

## Features in this Virtualmin Module
* **PlugnPay Ready**: Supported by official PlugnPay payment processing extensions.
* **Modular Architecture**: Features thousands of extensions and themes.
* **Easy Installation**: Sets up directory structure and file permissions ready for setup.
