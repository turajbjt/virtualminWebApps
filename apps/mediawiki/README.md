# MediaWiki for Virtualmin

[MediaWiki](https://www.mediawiki.org/) is the extremely powerful, scalable open-source wiki software that powers Wikipedia and thousands of other knowledge bases.

## Features in this Virtualmin Module
* **Virtualmin Pro Replacement**: Free, unrestricted community installer.
* **Fully Automated CLI Installation**: Provisions the database, schema, administrator user, and `LocalSettings.php` without requiring browser setup.
* **LTS & Current Releases**: Supports MediaWiki 1.42 (current) and 1.39 (LTS).
