# Ghost for Virtualmin

[Ghost](https://ghost.org/) is a powerful open-source technology platform for modern independent publishers, blogs, and newsletter creators.

## Features in this Virtualmin Module
* **Virtualmin Pro Replacement**: Free, unrestricted community installer.
* **Isolated Runtime**: Managed in an isolated container instance to ensure Node.js runtime isolation while storing content in `/home/<domain>/ghost-content`.
* **Database Wiring**: Pre-configures MariaDB/MySQL connection settings.
* **Web Reverse Proxy**: Pre-configures Apache/Nginx reverse proxying to the domain root.
