# Drupal for Virtualmin

[Drupal](https://www.drupal.org/) is a leading open-source content management framework used by global enterprises, governments, and higher education.

## Features in this Virtualmin Module
* **Virtualmin Pro Replacement**: Free, unrestricted community installer.
* **Pre-configured Environment**: Automatically configures `sites/default/settings.php` with database credentials, table prefixes, and security salts.
* **Flexible Subdirectory**: Install to domain root or a custom subfolder (`/drupal/`).
