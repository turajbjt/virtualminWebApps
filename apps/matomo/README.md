# Matomo for Virtualmin

[Matomo](https://matomo.org/) (formerly Piwik) is the leading open-source alternative to Google Analytics that gives you 100% data ownership and privacy compliance (GDPR, HIPAA, CCPA).

## Features in this Virtualmin Module
* **Virtualmin Pro Equivalent**: Free, unrestricted community installer.
* **Pre-configured Database & Salt**: Automatically generates database connection configuration and unique security salts in `config/config.ini.php`.
* **Automated Archiving Cron**: Sets up recurring archiving jobs (`core:archive`) in crontab to ensure high-traffic reports load instantly.
