# WooCommerce for Virtualmin

[WooCommerce](https://woocommerce.com/) is the open-source e-commerce platform built on WordPress, powering over 25% of all top 1 million online stores.

## Features in this Virtualmin Module
* **Full Automated Provisioning**: Uses WP-CLI under the hood to automatically install WordPress core, configure `wp-config.php`, initialize the database, and install and activate the WooCommerce plugin in a single operation.
* **Flexible Directory**: Install to domain root or a subdirectory (`/shop`).
