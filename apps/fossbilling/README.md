# FOSSBilling for Virtualmin

[FOSSBilling](https://fossbilling.org/) is the modern, open-source community fork of **BoxBilling**, designed to manage hosting, invoicing, customer ticketing, and digital product carts.

## Features in this Virtualmin Module
* **BoxBilling Successor**: Compatible with BoxBilling payment integrations including PlugnPay.
* **Automated Cron Scheduling**: Automatically provisions recurring invoice and service suspension background jobs in the virtual server user's crontab.
* **Database Wiring**: Pre-creates MariaDB/MySQL credentials ready for store activation.
