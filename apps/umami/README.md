# Umami for Virtualmin

[Umami](https://umami.is/) is an open-source, privacy-focused alternative to Google Analytics that collects no personal data and requires no cookie banners.

## Features in this Virtualmin Module
* **Privacy Focused**: GDPR and CCPA compliant out of the box.
* **Database Connection**: Automatically configures the MariaDB/MySQL connection string.
* **Isolated Daemon**: Managed by systemd with Apache/Nginx reverse proxying to the domain root.
