# Joomla! for Virtualmin

[Joomla!](https://www.joomla.org/) is a mobile-ready and user-friendly open-source content management system.

## Features in this Virtualmin Module
* **Virtualmin Pro Replacement**: Free, unrestricted community installer.
* **Pre-configured Database**: Pre-creates MariaDB/MySQL database credentials ready for store activation.
* **Flexible Subdirectory**: Install to domain root or a custom subfolder (`/cms/`).
