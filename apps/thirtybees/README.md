# Thirty Bees for Virtualmin

[Thirty Bees](https://thirtybees.com/) is a high-performance open-source e-commerce platform focused on stability, page speed, and seamless PHP support.

## Features in this Virtualmin Module
* **High Performance**: Optimized for fast page load times and minimal server resource usage.
* **Automated Installation**: Provisions the database, administrator credentials, and store configuration via CLI.
* **PlugnPay Ready**: Official PlugnPay module integration support.
* **Security**: Automatically removes installer files post-configuration.
