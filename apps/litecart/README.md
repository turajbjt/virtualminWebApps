# LiteCart for Virtualmin

[LiteCart](https://www.litecart.net/) is a free, modern, and lightweight open-source e-commerce platform built for speed and simplicity.

## Features in this Virtualmin Module
* **Ultra Lightweight**: Highly optimized PHP code without bloated frameworks.
* **Pre-configured Database**: Prepares MySQL/MariaDB database and user credentials.
* **Subdirectory Flexibility**: Install to domain root or a custom subfolder (`/store/`).
