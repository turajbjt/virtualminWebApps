# SuiteCRM Virtualmin Installer

**SuiteCRM** is an enterprise-ready, open-source Customer Relationship Management (CRM) application providing 360-degree customer views, sales automation, marketing campaigns, and workflow orchestration.

## Architecture
- **Language**: PHP 8.1+ / 8.2+
- **Database**: MariaDB / MySQL
- **Web Server**: Apache or Nginx

## Installation
Installed via Virtualmin Webmin GUI under **Server Configuration -> Manage Web Apps -> SuiteCRM** or using the CLI:
```bash
./setup.sh install
```
