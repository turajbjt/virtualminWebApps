# Uptime Kuma for Virtualmin

[Uptime Kuma](https://uptime.kuma.pet/) is a self-hosted monitoring tool that provides HTTP, TCP, Ping, DNS, and Certificate expiration monitoring with status pages and alerts.

## Features in this Virtualmin Module
* **Isolated Daemon**: Runs in an isolated container instance with automated systemd lifecycle management.
* **WebSocket Reverse Proxy**: Automatically configures Apache/Nginx reverse proxying with full WebSocket forwarding for real-time dashboard updates.
* **Low Resource Usage**: Uses minimal RAM and CPU.
