# osCommerce Virtualmin Installer

**osCommerce** is a classic and pioneer open-source e-commerce platform and online store-management software program.

## Architecture
- **Language**: PHP 8.1+
- **Database**: MariaDB / MySQL
- **Web Server**: Apache or Nginx with URL rewriting enabled.

## Installation
Installed via Virtualmin Webmin GUI under **Server Configuration -> Manage Web Apps -> osCommerce** or using the suite's CLI:
```bash
./setup.sh install
```
