# Zen Cart for Virtualmin

[Zen Cart](https://www.zen-cart.com/) is a truly free, user-friendly, open source shopping cart software.

## Features in this Virtualmin Module
* **Pre-wired Database**: Automatically prepares the MariaDB/MySQL database and user credentials.
* **PlugnPay Module Ready**: Compatible with classic PlugnPay payment processing gateway plugins.
* **Easy Subdirectory Selection**: Install to root or custom subdirectory.
