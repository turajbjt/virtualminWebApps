# Invoice Ninja for Virtualmin

[Invoice Ninja](https://www.invoiceninja.com/) is the leading open-source platform for invoicing, quotes, customer payments, expense tracking, and time logging.

## Features in this Virtualmin Module
* **Virtualmin Pro Replacement**: Free, unrestricted community installer.
* **Pre-bundled Dependencies**: Uses official release tarballs with all PHP vendor libraries compiled.
* **Automated Scheduler**: Registers Laravel's schedule runner in the user's crontab for automatic recurring invoices and payment reminders.
