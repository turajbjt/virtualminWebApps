# CubeCart for Virtualmin

[CubeCart](https://www.cubecart.com/) is a powerful, fully-featured open source e-commerce script used by thousands of merchants.

## Features in this Virtualmin Module
* **Full-featured Storefront**: Complete catalog, shipping, tax, and order management.
* **Database Provisioning**: Automatically configures the MariaDB/MySQL database and user credentials.
* **Subdirectory Flexibility**: Supports installation to document root or custom subfolder (`/store/`).
