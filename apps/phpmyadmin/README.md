# phpMyAdmin Virtualmin Installer

**phpMyAdmin** is a free software tool written in PHP, intended to handle the administration of MySQL and MariaDB over the Web. It supports a wide range of operations on MySQL and MariaDB databases, tables, columns, relations, indexes, users, and permissions.

## Architecture
- **Language**: PHP 8.0+ / 8.1+ / 8.2+
- **Database**: MariaDB / MySQL
- **Web Server**: Apache or Nginx

## Installation
Installed via Virtualmin Webmin GUI under **Server Configuration -> Manage Web Apps -> phpMyAdmin** or using the CLI:
```bash
./setup.sh install
```
Default installation directory: `/phpmyadmin` or document root.
